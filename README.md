# BookMyShow-Style Movie Booking Website

A Django-based movie ticket booking website inspired by the BookMyShow user experience.

## Features

- User registration
- User login and logout
- Movie listing
- Movie search interface
- Movie ticket booking
- Booking history
- Ticket cancellation
- Django authentication
- Database integration
- Responsive frontend

## Technology Stack

- Python
- Django
- HTML
- CSS
- JavaScript
- SQLite for local development
- Git and GitHub
